# Doom Spiral Balance Update

## English

- Doom Spiral now sets Destiny to 0 when played.
- At the start of each turn, Doom Spiral adds a Misfortune to your hand; Doom Spiral+ adds Misfortune+.
- Doom Spiral no longer repeatedly lowers Destiny at the start of each turn.
- Updated English and Simplified Chinese card and power text, with automatic Innate rendering preserved to prevent duplicate keywords.

## 简体中文

- “噩运螺旋”现在会在打出时将命运设为 0。
- 每回合开始时，“噩运螺旋”会将一张噩运加入手牌；“噩运螺旋+”改为加入噩运+。
- “噩运螺旋”不再于每回合开始时反复降低命运。
- 已同步更新英文和简体中文的卡牌及能力文本，并保留系统自动显示的“固有”，避免关键词重复。
