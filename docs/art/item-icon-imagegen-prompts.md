# Diviner Relic And Potion Icon Prompts

These prompts cover the implemented Diviner relic and potion icon assets. Use them for final painted replacements of the current simple placeholder-style icons.

## Shared Relic Icon Prompt

Polished fantasy deckbuilder relic icon, square 1:1 crop, centered object, transparent background, readable at 128x128 and 256x256. Match the Diviner visual language: dark indigo shadows, teal divination glow, pale ivory highlights, muted brass/gold metal, subtle crimson bad-omen accents. Use one clear central object with a strong silhouette, soft painterly rim light, crisp edges, no text, no letters, no numbers, no UI frame, no watermark, no clutter.

For `*_outline.png` relic variants: create a clean readable dark silhouette of the same object on transparent background, slightly expanded contour, minimal internal detail, no glow clutter.

## Shared Potion Icon Prompt

Polished fantasy deckbuilder potion icon, square 1:1 crop, centered small bottle/object, transparent background, readable at 128x128. Match the Diviner palette: dark glass, teal crystal glow, muted gold stoppers/seals, ivory highlights, crimson misfortune liquid where appropriate. Keep the bottle shape distinct for each potion. No text, no letters, no numbers, no UI frame, no watermark, no clutter.

For `*_outline.png` potion variants: create a clean readable dark silhouette of the same bottle/object on transparent background, slightly expanded contour, minimal internal detail.
