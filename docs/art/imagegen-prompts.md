# Diviner Image Generation Prompts

These prompts cover the 92 implemented Diviner cards and the current starter relic, Crystal Ball.

Use the existing Diviner character art as character reference when a prompt mentions the Diviner. Use the matching current portrait or relic image as scratch/composition reference if you attach one, but redraw it as polished final art rather than preserving placeholder linework.

## Shared Card Prompt Prefix

Polished simple fantasy deckbuilder card portrait, landscape crop, 4:3 aspect ratio, readable at thumbnail size. Match the attached Diviner character design when a person appears: hooded occult seer, crescent staff motifs, crystal-ball fortune telling, quiet confidence. Use attached scratch art only as rough composition reference. One clear central symbol or action, dark indigo or blue-green background with a mild vignette, restrained teal, ivory, muted crimson, and warm gold accents, soft painterly lighting, crisp silhouette, no card frame, no text, no letters, no numbers, no UI, no watermark, no clutter, no extra limbs, no gore. No frame ,no white space around the generated image.

## Shared Relic Prompt Prefix

Polished fantasy deckbuilder relic icon, centered object, 1:1 crop, readable as a small game icon. Match the Diviner palette: dark indigo, teal glow, pale ivory highlights, muted gold metal, subtle crimson omen accents. Use attached relic scratch art only as rough silhouette reference. No text, no letters, no numbers, no UI frame, no watermark, no clutter.
